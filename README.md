# Power Pots

**Power Pots** is a small Minecraft mod that adds *powered* versions of Botany Pots.  
These powered pots use energy (FE/RF) to grow crops faster or yield more output.

This is a **port / fork** of [FTB Power Pots](https://github.com/FTBTeam/FTB-Power-Pots).

---

## Features
- Adds multiple tiers of *Power Pots*, each consuming more energy and growing faster.
- Fully compatible with **Botany Pots** crops and recipes.

---

## Requirements
- Minecraft & Neoforge
- Botany Pots
- Bookshelf
- Mekanism (optional, for recipes)
